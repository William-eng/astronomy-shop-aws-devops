# Astronomy Shop on AWS

An end-to-end AWS Cloud and DevOps Engineering portfolio project.

## Objective

Deploy and operate the OpenTelemetry Astronomy Shop microservices
application using AWS, Terraform, Amazon EKS, GitHub Actions,
OpenTelemetry, monitoring, security, and FinOps practices.

## Implementation Phases

1. AWS Foundation and Development Environment
2. Terraform Infrastructure and Networking
3. Amazon EKS Platform
4. Astronomy Shop Application Deployment
5. CI/CD with GitHub Actions
6. Observability and Monitoring
7. Security, Backup, and Reliability
8. FinOps and Performance Optimization
9. Final Documentation and Project Review

## Project Status

Frontend CI/CD: build and ECR push confirmed in recorded pipeline evidence.

Phase 6: EKS deployment preparation and observability baseline statically validated; not deployed. The $10 monthly budget blocks a live EKS environment. See [Phase 6 guide](docs/phase-06-eks-deployment.md) and [image mapping](docs/phase-06-image-map.md).
